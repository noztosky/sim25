# 1kHz RPC Latency Benchmark Analysis (10s Average)

본 문서는 1kHz(1,000us 주기) 환경에서 RPC 방식의 통신 지연 특성을 분석한 결과입니다. 대조군(Baseline) 데이터로서 4kHz 결과와 비교 연구에 활용됩니다.

## 1. 실험 요약
- **Target IMU Hz**: 1,000 Hz (1ms)
- **Target PWM Hz**: 400 Hz (2.5ms)
- **Measured IMU Hz**: 953 Hz (유효 샘플링 성능 약 95.3%)
- **Measured PWM Hz**: 398 Hz (안정적)
- **Real-Time Factor (RTF)**: 0.99

## 3. 분석 결과 및 시사점

### 3.1 충분한 통신 마진 (Safety Margin)
- 1kHz 목표 주기는 1,000us이며, RPC의 평균 응답 시간(약 150~200us)은 이 주기의 20% 미만을 차지함.
- 따라서 대부분의 샘플(99.9% 이상)이 5% 지연 이내의 [0]번 버킷에 집중됨. 이는 1kHz 이하 루프에서는 RPC가 매우 신뢰성 있는 통신 수단임을 증명함.

### 3.2 4kHz 결과와의 대조 (Scaling Issue)
- 동일한 RPC 오버헤드를 가짐에도 불구하고, 주기가 250us으로 짧아진 4kHz 실험에서는 지터 비율이 급상승함.
- 이는 통신 방식의 절대적 지연 시간은 고정되어 있으나, 제어 주파수가 올라감에 따라 상대적인 **'지연 마진'**이 소멸하여 발생하는 현상임.

### 3.3 결론
- 1kHz SIL 시뮬레이션에서는 RPC 방식이 충분한 결정성을 보장함.
- 하지만 고주파수(4kHz 이상) 제어로 확장 시, 고정된 통신 오버헤드를 극복할 수 있는 **SHM(공유 메모리)으로의 전환이 필수적**이라는 강력한 근거가 됨.
